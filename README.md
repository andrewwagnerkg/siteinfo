# Сайт компании

Сайт IT-компании. Его разрабатывают, наполняют и публикуют агенты Claude Code.
Любой участник команды может клонировать репозиторий и писать запросы агентам.

## Что нужно установить
- Git
- Node.js (актуальная LTS-версия)
- GitHub CLI (`gh`) и вход в аккаунт: `gh auth login`
- Claude Code (нужна платная подписка Claude)

## Начало работы
```bash
git clone <адрес репозитория>
cd <папка репозитория>
npm install
claude
```

В Claude Code просто опишите, что нужно, например:
- «Добавь страницу контактов с адресом, телефоном и формой заявки»
- «Добавь новость о запуске нового проекта»
- «Открой вакансию Junior Frontend Developer, удалённо»
- «Сделай кнопки на главной заметнее»

Агенты сами создадут ветку, внесут изменения, проверят их и откроют pull request.

## Что дальше
1. Другой участник смотрит pull request и одобряет его.
2. После слияния в `main` сайт автоматически обновляется на dev-стенде (GitHub Pages).
3. Когда версия всех устраивает — любой участник просит: «опубликуй текущую версию на prod» (prod пока не настроен).

## Команда агентов
| Агент | Что делает |
|---|---|
| developer | Код страниц и компонентов |
| designer | Дизайн-система и внешний вид |
| content | Тексты и переводы (en, ru, ky) |
| tester | Проверяет сборку, тесты, переводы, ссылки |
| publisher | Ветки, pull request, релизы |

Правила для агентов — в `CLAUDE.md`, описания агентов — в `.claude/agents/`.
