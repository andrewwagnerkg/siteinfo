# Дизайн-система

Статус: заглушка. Заполняет агент `designer` при первом запуске проекта.
Пока нет брендбука — используется нейтральная палитра. Когда появятся логотип и фирменные цвета, меняются только токены.

## Принципы
- Ясность важнее «вау-эффекта».
- Сдержанная анимация, только CSS, с учётом `prefers-reduced-motion`.
- Не больше одного эффекта (свечение, «стекло») на странице.
- Mobile first: 360 / 768 / 1280 px.
- Контраст текста — WCAG AA.

## Адаптивность (обязательно)
Сайт должен корректно работать на любых экранах. Подход — mobile first.

| Устройство | Ширина для проверки | Брейкпоинт Tailwind |
|---|---|---|
| Телефон | 360, 390 px | базовые стили |
| Планшет | 768 px (портрет и альбом) | `md` |
| Ноутбук | 1024, 1280 px | `lg`, `xl` |
| Большой монитор | 1920 px | `2xl` |

Правила:
- Сначала стили для телефона, затем расширение через брейкпоинты.
- Плавные размеры шрифтов и отступов через `clamp()`.
- Сетки: 1 колонка → 2 → 3–4.
- Контейнер с максимальной шириной; строка текста не длиннее ~75 символов.
- Мобильное меню (бургер) с доступом с клавиатуры.
- Тач-цели не меньше 44×44 px.
- Адаптивные изображения (`srcset`/`sizes` через `astro:assets`).
- Нет горизонтальной прокрутки страницы ни на одной ширине.
- Длинные слова на ru и ky не ломают вёрстку (`overflow-wrap`, `hyphens`).

## Токены
_Заполнить:_ цвета (фон, текст, акцент, состояния), шрифты и размеры, отступы, радиусы, тени, брейкпоинты.

## Компоненты
_Заполнить:_ кнопки, карточки (услуга, кейс, новость, вакансия), шапка, футер, переключатель языка, форма, секции главной.
