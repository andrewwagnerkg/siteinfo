## Context

A private clinic network with 120 employees and 4 branches ran its online booking system on an old server in the office. The system went down during peak hours, and the hardware was expensive to maintain.

## Task

"Online booking must work around the clock, and we want to stop paying for hardware we don't use."

## What we did

- Audited the current infrastructure and costs.
- Packaged the application in containers and moved it to a managed cloud in stages, with no downtime.
- Described the infrastructure as code and set up backups, monitoring and alerts.
- Configured access control and encryption for patient data.

- **Stack:** Docker, Kubernetes, Terraform, PostgreSQL, GitHub Actions.
- **Timeline:** 3 months.
- **Team:** 3 people: DevOps engineer, backend developer, project manager.

## Result

- Infrastructure costs: 35% lower.
- Online booking availability: 99.9%.
- Recovery after a failure: from several hours to 15 minutes.
